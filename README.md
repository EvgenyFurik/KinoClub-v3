# KinoClub-v3

Учебный проект — адаптивная страница киноклуба с подборкой любимых фильмов и поиском по названию в реальном времени.

## Возможности

- Сетка карточек фильмов: постер, название и краткое описание
- Живой поиск по названию — карточки фильтруются по мере ввода текста (без учёта регистра)
- Адаптивная вёрстка под три размера экрана
- Тёмная тема оформления

## Технологии

- **HTML5** — семантическая разметка (`header`, `nav`, список `ol`)
- **CSS3** — Flexbox, CSS Grid, медиазапросы
- **JavaScript (ванильный)** — работа с DOM и событиями, без библиотек и сборщиков

## Структура проекта

```
KinoClub-v3/
├── index.html    # разметка страницы
├── style.css     # стили и адаптивность
├── script.js     # логика поиска
├── img/          # постеры фильмов
└── README.md
```

## Запуск

Сборка не требуется:

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что рядом с `index.html` лежит папка `img/` с постерами.
3. Откройте `index.html` в браузере.

## Как работает поиск

В `script.js` на поле `#search` навешивается обработчик события `input`. При каждом изменении текста скрипт перебирает все карточки `.film`, сравнивает введённую строку с заголовком `<h2>` (в нижнем регистре) и скрывает карточки, в названии которых нет совпадения (`display: none`).

## Как добавить фильм

Добавьте в список `<ol class="topfive">` в `index.html` новый элемент:

```html
<li class="film">
    <h2>Название фильма</h2>
    <img src="img/poster.jpeg" alt="Название фильма" class="imgfilm">
    <p>Краткое описание фильма...</p>
</li>
```

Положите постер в папку `img/` — поиск подхватит новую карточку автоматически.
